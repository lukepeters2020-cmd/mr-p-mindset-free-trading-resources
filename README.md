## Try the code

With a current Node.js installation, run `node risk-math.mjs` for the documented teaching example, then `node --test risk-math.test.mjs` for checks. No package installation, account, data connection or API key is required. The utilities do not connect to a broker or place trades.

The cash-only whole-share sizing model assumes one entry, an intended stop and a stated per-share cost estimate. It is not suitable for sizing futures, options, margin or multi-currency positions without additional modelling. Planned loss is not a guaranteed maximum loss.
